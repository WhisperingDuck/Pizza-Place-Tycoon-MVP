# Pizza Place Tycoon

Open **[pizza-place-tycoon.html](pizza-place-tycoon.html)** in a browser from a local folder. The one-day review starts with empty stock on Route 1. Play from preparation through closing, then use the receipt to plan the next morning. **Reset sample** repeats the same day.

- [Walkthrough and state map](STATE-MAP.md)
- [Editable game copy](source/content.json) and [event preview guide](COPY.md)
- [Candidate engine provenance and checksums](checkpoint/PROVENANCE.md)
- [Design and interaction checks](design-qa.md)

The standalone file includes the code, drawing and draft text. Run `python3 package.py` after editing the source. Use the design review to decide whether the stand and pace work before adapting the remaining screens.
